College Placement Management System

About the Project

The College Placement Management System is a Python-based project designed to manage student placement information in a simple and organized way.

Features

- Add Student Details
- View Student Records
- Search Student Information
- Manage Placement Status
- Simple and User-Friendly Interface

Technologies Used

- Python

Purpose

This project helps organize student details and placement information efficiently. It was developed as a learning project to practice Python programming.

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run "main.py" using Python.
